## How I work

```text
Find the behavioural break → form a measurable hypothesis →
test the smallest useful intervention → learn and iterate at scale
```

- Start with a customer journey and the specific moment where intent is lost.
- Pair qualitative research with behavioural and business data.
- Define a clear hypothesis, success metric, and smallest viable test.
- Build adoption with product, operations, lifecycle touchpoints, and strong cross-functional collaboration.
- Use automation to support human judgment—not to obscure it.
